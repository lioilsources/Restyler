Kontakt

Napiš na business@olin.now. Přidej model telefonu, verzi appky (Nastavení telefonu → Aplikace) a co se stalo.

Časté potíže

  • „Tvář jsme nenašli“: použij čelní portrét jednoho člověka, bez ruky před tváří.
  • „Server je teď vytížený“: render server zpracovává jiné úlohy. Zkus to za pár minut, nic se nespotřebovalo.
  • „Server není dostupný“: zkontroluj připojení k internetu a zkus to znovu.
  • Render trvá dlouho: obrázek trvá desítky sekund, klip Oživit i několik minut. Appku můžeš zavřít, výsledek se stáhne po návratu.

Smazání dat

Projekty v telefonu smažeš v appce nebo smazáním appky. O smazání dat na serveru požádej e-mailem, viz Ochrana soukromí.

Common issues

  • No face found: use a front-facing portrait of one person, no hand in front of the face.
  • The server is busy: the render server is working on other jobs. Try again in a few minutes; nothing was used up.
  • Server not reachable: check your internet connection and try again.
  • A render takes long: an image takes tens of seconds, an “Animate” clip up to several minutes. You can close the app; the result downloads when you come back.

Deleting data

Delete projects on the phone in the app or by removing the app. To have data deleted on the server, ask by email; see the Privacy Policy.
